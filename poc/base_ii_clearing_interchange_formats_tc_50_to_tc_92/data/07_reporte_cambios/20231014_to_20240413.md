### TC 52 - TCR 4

- **`17-20`** — Network Identification Code
  - Ficha (description)
    - Antes: 'Indicates debit product used. The entry must be numeric and may be zeros. This field is mapped to the SMS Network ID field. 0002 = Visa (this is the default if the TCR 4 is not included) 0004 = Plus This field is included in all non-Visa presentments acquired by the Single Message System. This field is included in all non-Visa presentments acquired by the VisaNet Debit System. Plus Issuers are required to retain and return the Network Identification Code in subsequent U.S. domestic dispute financials and retrieval requests if this field was received in the original transaction.'
    - Ahora: 'Indicates debit product used. The entry must be numeric and may be zeros. This field is mapped to the V.I.P. Network ID field. 0002 = Visa (this is the default if the TCR 4 is not included) 0004 = Plus This field is included in all non-Visa original full financial transactions acquired by V.I.P. This field is included in all non-Visa presentments acquired by the VisaNet Debit System. Plus Issuers are required to retain and return the Network Identification Code in subsequent U.S. domestic dispute financials and retrieval requests if this field was received in the original transaction.'
    - Razón (IA): El campo se redefinio de 'SMS Network ID' a 'V.I.P. Network ID', lo que cambia el significado técnico del campo en el contexto de Visa.
